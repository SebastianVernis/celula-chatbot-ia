🚀 PRÓXIMOS PASOS (EN ORDEN):

PASO 1: Configurar Variables de Entorno
────────────────────────────────────────
1. Ir a: AWS Amplify Console
2. Navegar a: App Settings > Environment variables
3. Agregar:
   • GEMINI_API_KEY = (tu API key de Google Gemini)
   • RESEND_API_KEY = (tu API key de Resend)
   • CONTACT_EMAIL = contacto@grupomusicalcelula.com

PASO 2: Deployment
────────────────────────────────────────
$ git add .
$ git commit -m "feat: Complete AWS Lambda integration"
$ git push origin main

(AWS Amplify desplegará automáticamente)

PASO 3: Verificar Deployment
────────────────────────────────────────
1. Esperar a que termine el build
2. Verificar en: Amplify Console > Hosting > Compute
3. Revisar logs del build

PASO 4: Testing
────────────────────────────────────────
# Test Chatbot
$ curl -X POST https://YOUR_APP.amplifyapp.com/api/chatbot \
  -H "Content-Type: application/json" \
  -d '{"history":[{"role":"user","parts":[{"text":"Hola"}]}]}'

# Test Email
$ curl -X POST https://YOUR_APP.amplifyapp.com/api/send-email \
  -H "Content-Type: application/json" \
  -d '{"type":"chatbot_lead","leadData":{"name":"Test","email":"test@test.com","phone":"123"}}'

# Test desde el sitio web
1. Abrir sitio web
2. Probar chatbot
3. Probar formulario de contacto

PASO 5: Monitoreo
────────────────────────────────────────
• CloudWatch Logs: /aws/lambda/chatbot y /aws/lambda/send-email
• Métricas: Invocations, Errors, Duration, Throttles
• Primeras 24 horas: Monitoreo activo
