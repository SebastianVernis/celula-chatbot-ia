# Mapeo de Clases CSS - Antigua vs Nueva Estructura

## Navegación (NAV-MENU)

### Clases Antiguas → Nuevas
- `.site-header` → `.nav-menu-container`
- `#SITE_HEADER` → `.nav-menu-container`
- `.nav-container` → `.nav-menu-wrapper`
- `.nav-menu` → `.nav-menu` (sin cambios)
- `.nav-item` → `.nav-menu-item`
- `.nav-link` → `.nav-menu-link`
- `.mobile-menu-toggle` → `.nav-menu-toggle`

### Ejemplo HTML
```html
<!-- ANTES -->
<header class="site-header" id="SITE_HEADER">
    <nav class="nav-container">
        <ul class="nav-menu">
            <li class="nav-item">
                <a href="#" class="nav-link">INICIO</a>
            </li>
        </ul>
        <button class="mobile-menu-toggle">

<!-- DESPUÉS -->
<header class="nav-menu-container">
    <nav class="nav-menu-wrapper">
        <ul class="nav-menu">
            <li class="nav-menu-item">
                <a href="#" class="nav-menu-link">INICIO</a>
            </li>
        </ul>
        <button class="nav-menu-toggle">
```
