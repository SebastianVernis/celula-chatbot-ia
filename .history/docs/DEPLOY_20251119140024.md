# Guía de Despliegue - Grupo Musical La Célula

## 📋 Requisitos Previos

- Node.js 18+ instalado
- Cuenta en Cloudflare Pages
- Repositorio en GitHub
- Variables de entorno configuradas

## 🚀 Despliegue en Cloudflare Pages

### 1. Preparación del Proyecto

```bash
# Instalar dependencias
npm install

# (Opcional) Ejecutar minificación de assets
npm run build
```

### 2. Configuración de Variables de Entorno

En el dashboard de Cloudflare Pages, configura las siguientes variables:

#### Variables de Producción:
- `NODE_VERSION`: `18` o superior
- `RESEND_API_KEY`: Tu clave API de Resend para envío de emails
- `CONTACT_EMAIL`: Email donde recibirás las solicitudes
- `GEMINI_API_KEY`: Tu clave API de Google Gemini para el chatbot
- `ENVIRONMENT`: `production`

### 3. Configuración del Build en Cloudflare

**IMPORTANTE**: Configura estos valores exactamente en el dashboard de Cloudflare Pages:

```
Build command: npm install
Build output directory: . (punto, no barra)
Root directory: / (dejar vacío)
Node version: 18
```

**Nota crítica**: 
- El `build output directory` debe ser `.` (punto) para que Cloudflare Pages encuentre correctamente las Functions y los node_modules
- El `wrangler.toml` está configurado con `nodejs_compat` flag para soportar módulos Node.js como Resend

### 4. Configuración Automática desde Git

Cloudflare Pages detectará automáticamente:
- El archivo `wrangler.toml` para configuración
- El archivo `package.json` para dependencias
- Las Cloudflare Functions en `/functions/api/`

## 🔧 Configuración de Resend

### Instalación Automática

La dependencia `resend` se instala automáticamente durante el build:

```json
{
  "dependencies": {
    "resend": "^4.0.0"
  }
}
```

### Uso en Functions

```javascript
import { Resend } from 'resend';

const resend = new Resend(env.RESEND_API_KEY);
```

## 📝 Variables de Entorno Requeridas

### Para el Sistema de Email (Resend):
- `RESEND_API_KEY`: Clave API de Resend
- `CONTACT_EMAIL`: Email destino para recibir mensajes

### Para el Chatbot:
- `GEMINI_API_KEY`: Clave API de Google Gemini

## 🔄 Proceso de Despliegue

### Despliegue Automático (Recomendado)

1. Conecta tu repositorio de GitHub a Cloudflare Pages
2. Configura las variables de entorno en el dashboard
3. Cada push a `main` desplegará automáticamente

### Despliegue Manual

```bash
# Usando Wrangler CLI
npm install -g wrangler

# Login a Cloudflare
wrangler login

# Desplegar
wrangler pages deploy .
```

## 🐛 Troubleshooting

### Error: Module not found 'resend'

**Solución**: Asegúrate de que `package.json` existe y contiene la dependencia:
```json
{
  "dependencies": {
    "resend": "^4.0.0"
  }
}
```

### Error: Variables de entorno no definidas

**Solución**: Configura las variables en:
- Cloudflare Dashboard → Pages → Settings → Environment Variables

### Error: CORS

**Solución**: Verifica que tu dominio esté en la lista de `ALLOWED_ORIGINS` en `/functions/api/send-email.js`
