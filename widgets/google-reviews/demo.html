💡 Nota:

Este demo usa datos estáticos de ejemplo. Para usar reseñas reales de Google, necesitas configurar Featurable o actualizar los datos en el código.

📝 Código de Implementación

<!-- Incluir CSS -->
<link rel="stylesheet" href="widgets/google-reviews/google-reviews-widget.css">

<!-- Contenedor del widget -->
<div id="google-reviews-container"></div>

<!-- Incluir JavaScript -->
<script src="widgets/google-reviews/google-reviews-widget.js"></script>

<script>
  document.addEventListener('DOMContentLoaded', function() {
    new GoogleReviewsWidget({
      featurableId: 'TU_FEATURABLE_ID', // O null para datos estáticos
      containerId: 'google-reviews-container',
      layout: 'carousel', // 'carousel', 'badge', o 'grid'
      maxReviews: 10,
      autoplay: true,
      autoplaySpeed: 5000
    });
  });
</script>

🚀 Cómo empezar

Opción 1: Con Featurable (Recomendado - GRATIS)

  1. Regístrate en featurable.com
  2. Crea un widget con tu Google Place ID
  3. Copia tu Widget ID
  4. Úsalo en la configuración del widget

Opción 2: Datos Estáticos

  1. Edita el método loadStaticData() en google-reviews-widget.js
  2. Agrega tus reseñas reales manualmente
  3. No incluyas featurableId en la configuración
⚠️ Limitación de Google Places API:

La API oficial de Google solo devuelve las 5 reseñas más recientes. Featurable no tiene esta limitación y es completamente gratuito.
